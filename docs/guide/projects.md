# Projects

A project is a container — a name, a description, and an optional total budget — that
tasks, notes, and pots can link to. Use it to group everything related to one goal
("Kitchen renovation", "Holiday 2026") in one place instead of hunting across sections.

## Project budget progress

If a project has a budget set, its detail page shows a progress bar of total saved
(across every pot linked to that project) against that budget, plus each linked pot's
own on-track/behind/ahead status. An **"Add pot to this project"** link on the page
creates a new pot with the project pre-selected, and returns you to the project page
once saved — so linking a new savings goal to a project doesn't mean bouncing between
sections to set it up.
