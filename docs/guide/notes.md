# Notes

Free-form notes with a title and a markdown body, standalone or linked to a project.
Markdown is rendered live as you type.

## AI features (optional, on-demand)

Both require an AI provider configured first (Settings → AI, see [Settings](settings.md))
— with none configured, both buttons just say so instead of doing anything. Neither ever
runs automatically; you always click to trigger them, and nothing is saved without a
separate confirmation.

- **Suggest links** — sends the note to the configured provider and comes back with
  clickable suggested actions: create a linked task, link the note to an existing
  project/pot/one-off payment, or create a new project from it. Nothing happens until you
  click one of the suggestions.
- **Enrich note** — asks the provider to rewrite or expand the note body, and streams
  the result back as a preview. The preview is not saved automatically — the original
  body is left untouched until you explicitly accept the rewrite.
