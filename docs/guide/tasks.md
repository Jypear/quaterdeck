# Tasks

A straightforward to-do list: each task has a title, an optional due date, a priority
(low/medium/high), and a status. Tick a task off directly from the list — no need to
open it first.

A task can optionally be linked to a **Project**, which makes it show up on that
project's detail page alongside its notes and pots.

Click a task's title to open its own detail page.

## Tasks as future payments

A task can also carry a `budget_amount` — for a large upcoming payment you want to track
as a task rather than a full [one-off outgoing](budget.md#one-off-outgoings) (e.g. a
reminder to "chase the deposit refund, ~£300" that isn't really a scheduled bill). Give
it a due date and it shows up on the [Calendar](calendar.md) like any other dated task.
